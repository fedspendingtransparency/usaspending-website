The Financial Assistance Action Types became available on 10/01/2026. These updates were refined in the <a target="_blank" rel="noopener noreferrer" href="https://tfx.treasury.gov/data-transparency/gsdm">Governmentwide Spending Data Model (GSDM)</a> v1.2 Annual Release in 2025 to address longstanding gaps, provide clear definitions, and better reflect the diversity of transactions, including terminations and financial closeouts.

For a full list of Action Types, view the RSS Domain Values on <a target="_blank" rel="noopener noreferrer" href="https://tfx.treasury.gov/data-transparency/gsdm#data">TFX</a>.
