The Financial Assistance Action Types became available on 10/01/2026. These updates were refined in the [Governmentwide Spending Data Model (GSDM)](https://tfx.treasury.gov/data-transparency/gsdm) v1.2 Annual Release in 2025 to address longstanding gaps, provide clear definitions, and better reflect the diversity of transactions, including terminations and financial closeouts. 

For a full list of Action Types, view the RSS Domain Values on [TFX](https://tfx.treasury.gov/data-transparency/gsdm#data).
