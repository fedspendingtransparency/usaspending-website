The updated Assistance Type domain values in the <a target="_blank" rel="noopener noreferrer" href="https://tfx.treasury.gov/data-transparency/gsdm">Governmentwide Spending Data Model (GSDM)</a> align federal financial assistance data with the new Grants Data Standards introduced in 2025. These changes modernize how assistance is categorized and ensure systems like SAM.gov, Grants.gov, and USAspending.gov classify assistance consistently.

Beginning October 1, 2026, agencies must use the new Assistance Types and attributes in their submissions. Legacy codes will be fully deprecated on that date. Agencies may begin submitting the new codes as early as March 1, 2026, but only the new codes will be accepted after the October implementation date.  

As these updates roll out, you will see changes to award categories on USAspending.gov. Several legacy Assistance Types—such as Block, Formula, and Project Grants—will merge into a single Grant category. Cooperative Agreements will continue to appear as their own category. 

While these legacy grant types will no longer appear as separate Assistance Type categories, users can use Assistance Type together with additional assistance-related attributes to further distinguish awards and (where the available data supports it) identify groupings that align with legacy categories such as Block, Formula, or Project Grants. This provides greater flexibility for understanding the characteristics of an assistance award while aligning USAspending with the updated federal data standards. 

Loan categories are also being updated. Guaranteed/Insured Loans becomes Loan Guarantee while Insurance becomes Indemnity/Insurance (non‑loan). 

USAspending.gov will also introduce new categories based on expanded domain values, including Asset Forfeiture/Equitable Sharing and Sale, Exchange, or Donation of Property and Goods. 

Together, these updates ensure the Award Type filter in Award Search reflects the latest federal data standards and gives users a clearer, more accurate picture of how federal funds flow across programs.
